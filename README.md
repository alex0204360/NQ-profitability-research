# NQ Profitability Research — V2

This second study asks whether price/volume patterns can choose direction, take
profit, stop loss and a 1–45 minute exit window with positive modeled profit after
costs. The first study found no qualifying directional patterns and did not test
a complete strategy's profitability.

Status: preregistered plan, before implementation. No profitable policy established.
See [the frozen research plan](docs/research.plan.md). Code, tests and results will
be published incrementally. Standard OHLCV input; no live feed or order execution.
