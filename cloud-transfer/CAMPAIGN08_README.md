# MNQ signal persistence and drift–diffusion experiment

This bounded campaign tested a two-completed-bar hysteresis rule, a past-only normal drift–diffusion probability filter, and their fixed intersection on the unchanged $8 gate. The intersection lost $1,799.50 under immediate stressed fills and $1,906.50 with a one-bar delay on the 14-session October upload. Its research bar-close drawdown was $1,902.50, above the newly specified $1,500 reference for a $25,000 account. The modeled probabilities were overconfident: Brier error 0.408 versus 0.239 for a constant base-rate forecast. No filter was retained for trading.
