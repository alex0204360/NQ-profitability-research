# Campaign 09: causal path representation, rejected

The single obstacle tested was whether the existing 18-feature snapshot omitted predictive information in recent price and volume history. We preregistered a causal 32-minute path, fit an unsupervised eight-component PCA on 15,508 training opportunities only, then trained two otherwise identical Ridge action-value students on the same robust ten-bar long/short targets. Both were scored on the same matured opportunities, with fixed next-open, one-contract time-ten replay under base, stress, extreme, immediate, and one-bar-delayed assumptions. The 2025 archive was not opened.

The original October 1–6 mean long/short rank correlations were 0.016 snapshot and 0.025 path; October 7–12 were 0.042 snapshot and 0.048 path. The incremental gains of 0.009 and 0.006 missed the preregistered 0.020 requirement. The 14-session October 13–29 upload produced seven path-agent trades and stressed net **−$109.50 immediate / −$128.50 delayed**, versus six snapshot trades at −$90.00 / −$132.00. The unchanged $8 gate made **+$196.50 immediate / −$1,250.00 delayed** on that same upload. The path agent's session-bootstrap lower expectancy was negative and extreme-cost net was negative. On the two-session October 30–November 2 upload, the path and snapshot students made the same single trade: +$155.50 immediate / +$68.50 delayed, far too little evidence to override the longer failure. The path agent failed the predictive, economic, sample-size, and uncertainty screens. No student was promoted.

The earlier $8 gate's 14-session immediate stressed research bar-close drawdown was **$816.50**, below the user's $1,500 reference; the one-bar-delayed value was **$1,657.00**. These are simulated one-contract bar-close figures, not an identified firm's trailing-drawdown test. The $25,000 account and $1,500 reference do not cure the unbounded gap risk of a time exit.

The first campaign09 run failed before fitting because the runner used the wrong protocol key. Its failed directory remains as an audit record; the one corrected run is `cloud_campaign09_retry1`, with immutable protocol, source hashes, model bundle, decision and trade journals, and manifest. No hyperparameter or threshold changed. The public [dashboard](/workspace/outputs/mnq_path_representation_dashboard.html) and aggregate JSON expose the fixed comparisons. All observations were previously opened Yahoo-labeled development data with unverified exact contract, roll rule, and interval convention. No broker orders were sent.

**Next priority:** obtain a contract-identified, append-only minute feed with exchange timestamp convention, roll rule, corrections, and executable cost schedule. Freeze a simple prediction test on genuinely new observations before another architecture or trading-policy campaign. Existing opened dates have already supported many failed searches; another tweak on them would add selection bias, not evidence.
