# Does the reversal probability determine remaining holding value?

The source experiment lowered Brier loss on model flips, but reliability for a flip need not imply predictability of trading P&L. Freeze before joining the new warning to holding-value labels. Use the canonical one first eligible discretionary decision per original trade across the same 40 and 60 exposed dates and both latencies. All alternative and original exit prices stay in the label path. Select observations by eligibility before label joins. If warning is censored retain the record; report usable pairs.

At a decision observe current entry range s and the published grid, fixed Laplace and reachability-only probabilities p of the parent's next-close sign reversal. Estimate two branch means for the signed holding label (original exit minus alternate executable open signed to the position), divided by the trade's entry range. Train each branch mean on earlier, strictly matured *original* exits. Use both actual next-close reversal state and endpoint label only after both outcomes mature. Maintain separate source/delay memories and a sum and count per branch. Shrink each branch mean toward the pooled historical mean with 16 equivalent observations; pooled mean = sum(normalized labels)/(16+n) with prior zero. At issuance predict H=s*((1−p)*mean_if_survives+p*mean_if_flips). For an opposite-sign parent versus open position issuance report separately or withhold signal; canonical discretionary decisions require original alignment. Controls: zero points, s times pooled historical mean, branch mixture using feasibility only, fixed Laplace weights. Additionally compute a clearly retrospective outcome-aware branch-selection diagnostic with the true next-close event and exactly the same past branch means. It cannot enter live policies.

Primary metric is MSE in points on common labeled decisions; report MAE, bias, rank, branch counts and paired five-session block intervals vs zero, pooled and feasibility. One-shot fixed-entry policy exits on H<0 and otherwise follows the original exit. Keep all original trades, $3/$6/$9 friction and identical fixed entries; report dollars saved/surrendered, net increments, frequency, concentration. This is a new exit-decision design; only advance to unrestricted replay if the grid mix beats pooled/feasibility MSE and net dollars on both latencies in both sources and is positive at stressed costs externally. No knobs fitted to these scores. The hindsight branch mixture tests the joint effects of branch-mean estimation and ex post outcome information, not attainable economic value.
