# Learn point magnitude from labels only after they mature

On the first discretionary favorable excursion the initial cell emitted about +28 external points against an average subsequently realized value near zero. A sign-symmetric correction increased the magnitude. Test whether a causal memory can learn a point scale and whether conditioning that memory on the volume contribution improves it over much simpler predictions.

One update per original trade, sampled at the frozen first eligibility. The network observes entry range s, the price score P and the volume score V. Let a=tanh(P/s−1), b=tanh((V−P)/s). Maintain separate fast-to-evaluate dot-product memories for a constant feature [1], price features [1,a], and price-volume features [1,a,b,ab]. For each head form k=u_today·u_old. For the interaction head this equals (1+a_today a_old)(1+b_today b_old), a nonnegative similarity. Maintain two state vectors A=Σu and B=Σu*(realized holding points at the previous decision / previous entry scale). With zero initial vectors and 16 equivalent unit-weight pseudo-observations at zero, output s*(u·B)/(16+u·A). No fitted hyperparameters or optimizer. The local head returns a causal point prediction and starts at zero. There is no forecast input from future outcomes. Only matured paper outcomes of the frozen original policy train the memory, including after a hypothetical early exit via a shadow original position.

Process chronologically, reset memory between data sources (40 discovery dates and 60 external dates) and between delays. Do not reset between days within a source. At a decision, use only labels whose original exit was known before that decision; enforce strict time comparison. Prior design and all dates are exposed. This is a chronological exploratory replay, not a blind validation. Compare zero points, frozen raw volume score, expanding constant memory, price memory and price-volume memory. Primary squared error in points; also mean absolute error, mean output, bias, rank and per-session paired 95% five-session circular block bootstrap for MSE differences vs zero/constant/price (10,000 draws, seed 2711). Report all dates including zero eligible trades. Operational diagnostic on identical baseline entries only: if prediction is negative, exit on the scheduled alternative open; otherwise keep the original exit. Report changed trades, delta dollars, fixed-ledger net at $3/$6/$9 and concentration. No extra trade costs arise when replacing one exit with one exit. This is a one-time decision design. Only justify a new full re-entry strategy experiment if the interaction head beats constant and price for MSE and fixed-ledger dollars in both panels and fill models, with positive stressed external fixed-entry net. Do not treat the reduced forecast magnitude alone as a discovery. No alternate priors, feature searches or new market data.
