# Forecast the probability that the parent changes its mind on the next close

The capacity study proved a reachable price barrier; the price-transfer studies found no after-cost action in their fixed representation. Return to human decision assistance. Forecast a concrete, observable event before it occurs: the next contiguous close makes the currently nonzero, warm parent forecast zero or opposite in sign. This endpoint is model behavior, not a price-return label. Test whether predicting the *probability* of this event improves on knowing only that reversal is possible.

Use the 100 exposed sessions and the original parent only. The issuance population is every warm, nonzero signal with scheduled next bar strictly before 15:55. No original trade or retrospective favorable excursion is required. At the close record current sign and normalized distance r=abs(f)/S. If S is zero or r>1 then p=0 exactly for the next contiguous bar. Otherwise reversal requires the next signed normalized close move to be ≤−r. The predictable denominator is next bar's encoder range, already known from the current high/low and existing lagged range. Missing next minutes censor the forecast and do not create a later replacement. Report the position-held subset using the archived next-open original trade/activation ledger separately; population-wide prediction is the primary endpoint.

Freeze a bounded tail-memory neuron. From every earlier resolved, contiguous scored bar, retain the adverse move m=−sign*(next close−current close)/next scale. At cutoffs k/16, k=0..16, maintain 17 counts of m≥k/16 using only observations from completed prior sessions within the same source (fit separately for 40 and 60). At a reachable distance linearly interpolate adjacent empirical survival probabilities. Twenty prior pseudo-bars contribute a Laplace signed-motion tail H(r)=0.5 exp(−2r) at each grid point. Clip probability only for the log-score at 1e−6, and give impossible events their exact zero probability for the Brier score. The neuron is a fixed grid of threshold cells with recurrent count updates; no fitted thresholds or random search. At r=1 use the final cell, preserving the exact clipping boundary.

Compare four outputs: a historical constant probability with prior 1/16 (mass 20); a reachability-only neuron (zero when impossible, otherwise empirical past reversal frequency over reachable bars, prior 1/4 with mass 20); reachable-only Laplace prior with no updates; and the grid memory. The primary comparator is reachability-only, both over all bars and restricted to reachable cases. Test without using outcomes from the issue date. Record Brier and log losses, prevalence, rank, mean prediction, bins [0,.05,.1,.2,.35,.5,1], and paired five-session circular-block intervals for Brier differences (10,000 draws, seed 604). Require the grid memory's upper Brier difference bound vs reachability-only to be below zero in both source panels, also among reachable cases, before freezing it as a warning candidate. Report comparison with the fixed Laplace comparator to distinguish evidence for barrier distance from evidence for learning its tail. This does not trigger an exit or any order.
